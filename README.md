# Python Automation Script

## Description
This project automates file operations using Python.

## Features
- File and folder operations
- Error handling using try-except
- Logging operations in automation.log
- User input support

## Technologies Used
- Python
- OS module
- Logging module

## Sample Output

## Files

- `automation.log` - Log records generated by the script
